# Katalog Game Favorit

Aplikasi web katalog game sederhana yang dibangun menggunakan React + Vite.

## Komponen
- **KartuGame**: Komponen untuk menampilkan informasi game.
  - Props: `judul` (string), `harga` (number), `levelKesulitan` (number), `gratis` (boolean).

## Cara Jalankan Proyek
1. Clone repositori: `git clone https://github.com/rsa3na/katalog-game-favorit.git`
2. Install dependensi: `npm install`
3. Jalankan server lokal: `npm run dev`
